# Grade Calculator

A Java-based grade calculator that computes student averages, letter grades, and statistics.

## Features

- Input multiple students and grades
- Calculates average, letter grade, highest, and lowest score per student
- Generates a clean summary report

## Tech Stack

- **Language:** Java
- **Concepts:** Object-oriented programming, class design, data structures

## How to Run

1. Clone the repository
git clone https://github.com/cdewitz/grade-calculator.git

2. Compile
javac *.java

3. Run
java Main

## Purpose

Built to demonstrate object-oriented design principles, separation of concerns across multiple classes, and data processing in Java.
